# Changed Artifact Plus Implementation Notes

Schema fields: `changed_artifacts`, `slice`, `test_first_proof`, `implementation_notes`, `validation`, `risks`, `rollback`, `next_action`.

## Changed Artifacts

List the files or outputs changed in this slice.

## Slice

Describe the smallest vertical behavior or documentation contract implemented.

## Test-First or Validator-First Proof

Record the failing test, validator, or eval observed before the change and the passing proof after the change.

## Implementation Notes

Summarize only the decisions needed for the next maintainer.

## Validation

List targeted and full validation commands with results.

## Risks

Name residual gaps, unsupported assumptions, or follow-up checks.

## Rollback

State how to revert the slice safely.

## Next Action

Name the next command, skill, or hardening slice.
