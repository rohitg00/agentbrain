# Wiki Update

Schema fields: `topic`, `sources_checked`, `freshness`, `changes`, `stale_rejections`, `privacy_review`, `validation`, `next_action`.

## Topic

Name the project knowledge area being updated.

## Sources Checked

List source files, docs, commits, issues, or external references with date or commit.

## Freshness

Record what makes this knowledge current and what would make it stale.

## Changes

Summarize durable documentation or context updates.

## Stale Rejections

List temporary task notes, outdated claims, unsupported assumptions, private data, or secrets that were not preserved.

## Privacy Review

Confirm no secret-like values, private context, or unnecessary raw user data were captured.

## Validation

Record validation, scrub, and review proof.

## Next Action

Name the next maintenance step or stop condition.
