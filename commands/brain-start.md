# /brain-start

Start from a raw user idea and produce a usable product brief.

## Loads

- `skills/brain-start/SKILL.md`
- `docs/question-ladder.md`
- `docs/grilling-protocol.md`
- `templates/product-brief.md`

## Behavior

1. Capture the raw request.
2. Ask only blocking questions.
3. State assumptions for non-blockers.
4. Grill the idea.
5. Produce a product brief.
6. Recommend the next command.
