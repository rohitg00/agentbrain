# Intake Summary

Schema fields: `state`, `decision`, `request`, `evidence_checked`, `fresh_validation_proof`, `facts`, `assumptions`, `open_questions`, `risks`, `blockers`, `next_recommended_state`.

## State

INTAKE

## Decision

Classify the raw request into the earliest safe Agent Brain state.

## Request

Record the user's request in neutral project language.

## Evidence Checked

List files, commands, logs, sources, or repository state inspected before routing.

## Fresh Validation Proof

Name any baseline validation command and result used for this routing decision.

## Facts

- Verified facts only.

## Assumptions

- Assumptions that affect routing.

## Open Questions

- Questions that would change scope, safety, or state.

## Risks

- Product, engineering, safety, privacy, or approval risks.

## Blockers

- Missing evidence, approval, or context that prevents safe progress.

## Next Recommended State

Name the next command, skills, and artifact to use.
