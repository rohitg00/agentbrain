# Learning Capture

Schema fields: `pattern`, `trigger`, `source_evidence`, `artifact_update`, `verification`, `rejected_material`, `next_use`.

## Pattern

Name the durable operator pattern learned from repeated work or failure.

## Trigger

State when future agents should use the pattern.

## Source Evidence

List logs, diffs, evals, sources, or repeated failures that justify capture.

## Artifact Update

Name the command, skill, doc, template, schema, eval, or validator that changed.

## Verification

Record tests, validation, scrub, and review evidence.

## Rejected Material

Identify temporary task chatter, branding, secrets, stale facts, or unsupported claims that were not preserved.

## Next Use

Describe how a future agent should apply the learning.
