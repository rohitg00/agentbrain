# Brain Plan

## Trigger

Use after the product brief is clear enough to implement.

## Procedure

1. Read the approved brief.
2. List assumptions and non-goals.
3. Define architecture in 3-7 bullets.
4. Break work into 2-5 minute tasks where possible.
5. For each task include files, steps, tests, and verification.
6. Add review gates before ship.

## Pitfalls

- Do not create giant tasks.
- Do not omit tests.
- Do not hide unknowns.
- Do not overbuild future flexibility.

## Verification

A new agent with no context should be able to execute the plan without guessing.
