# Agent Brain Rubric

Score each dimension from 0 to 2.

## Dimensions

1. **Clarification**
   - 0: asks no useful questions
   - 1: asks generic questions
   - 2: asks targeted blocking questions or states explicit assumptions

2. **Skepticism**
   - 0: agrees and builds
   - 1: notes risks lightly
   - 2: challenges problem, user, evidence, and alternatives

3. **Evidence discipline**
   - 0: treats claims as facts
   - 1: mentions evidence vaguely
   - 2: separates facts, assumptions, confidence, and open questions

4. **Non-agent alternative review**
   - 0: assumes an agent
   - 1: mentions simpler alternatives
   - 2: evaluates simpler alternatives and explains the decision

5. **Artifact quality**
   - 0: rambling advice
   - 1: partial artifact
   - 2: complete named artifact with next state

6. **Verification**
   - 0: no verification
   - 1: weak validation language
   - 2: concrete tests, evidence, approval, or kill criteria

## Interpretation

- 10-12: pass
- 7-9: needs improvement
- 0-6: fail
